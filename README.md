# ☕ Cafe Management System (Dynamic Web App)

A high-performance, dynamic web application built with a **C++ backend** and a modern frontend. This project demonstrates the ability to bridge low-level systems programming with a smooth user experience.

## 🚀 Key Features
- **Dynamic Frontend:** Implemented a responsive UI with a focus on high-fidelity aesthetics.
- **Modern Animations:** Integrated **Lottie animations** for an indulging and interactive user experience.
- **Robust Character Support:** Full **UTF-8 and Charset** optimization for global text rendering.
- **C++ Core:** Powered by the **Crow Web Framework** for lightning-fast request handling.
- **Embedded Database:** Utilizes **SQLite** for efficient, serverless data management.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+), LottieFiles.
- **Backend:** C++ (Crow Framework).
- **Database:** SQLite.
- **Tools:** Git, Linux, GCC/G++.
